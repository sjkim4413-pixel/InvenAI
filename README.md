# InvenAI

창고 사진의 상품·위치를 전산 재고와 비교하고, 오적재 알림부터 적재자 조치·검수·현장 이력까지 연결하는 물류 재고 관리 프로젝트입니다.

Android 앱과 Python 분석 서버는 [`project`](project)에 있습니다. Android Studio에서는 이 폴더를 프로젝트로 엽니다.

- [기능·구성·실행 방법](project/README.md)
- [시연 영상 시나리오와 발표 멘트](project/docs/demo-scenario.md)
- [실사 및 재적재 현장 로그 검증](project/test_photos/history50/README.md)

분석 모델, 비교 테스트 이미지, Android·Python 소스와 검증 코드를 포함합니다. 로컬 Firebase 설정, 서버 인증키, 가상환경과 빌드 결과는 제외하며 실행 준비는 프로젝트 README를 따릅니다.
