# 홈 화면의 실사 이상 재고 집계 수정

2026-11-25. 최신 앱: `app/build/outputs/apk/debug/app-debug.apk`.

## 원인과 수정

실사 오적재는 `auditAlerts`에 등록되지만 기존 홈 화면은 `inventory.status`만 집계했습니다. 그래서 이상 재고 대응 목록에는 실사 알림이 나오면서 홈의 이상 재고는 0개로 남았습니다.

홈이 회사별 실시간 재고와 미처리 실사 알림을 함께 구독하도록 수정했습니다. 기존 재고의 `ANOMALY`·`PENDING_QA` 상태와 미처리 실사 알림을 합쳐 집계합니다. 연결된 재고 문서의 **현재 전산 수량**을 표시하며, 같은 재고가 여러 실사에서 발견되거나 기존 이상 상태와 겹쳐도 수량은 한 번만 셉니다. 전체 재고 수량은 유지하고 해당 재고를 정상 집계에서 제외합니다.

실사 알림의 `OPEN`·`REVIEW_REQUESTED`는 조치 대상으로 남습니다. QA가 `RESOLVED`로 완료하면 홈에서 빠지며, 별도로 남은 기존 재고 이상 상태는 유지합니다. 재고 문서가 없거나 상품이 바뀌어 연결할 수 없는 알림은 수량을 만들어 넣지 않고 ‘재고 연결 확인’ 건수로 안내합니다. 알림 또는 재고 조회에 실패하면 정상·이상 수치를 `—`로 표시합니다.

집계 아래에 대상 위치 수와 실사 알림 건수를 함께 표시합니다. 창고 선택 조건은 홈 집계와 이상 재고 대응 목록에 동일하게 적용하며, 이상 재고 수치 카드를 눌러도 대응 목록으로 이동합니다.

## 검증

- [Android 빌드 및 단위 검사](android-build.log): 앱·테스트 APK 빌드 성공, 단위 검사 **32개 통과**. 신규 집계 검사는 7개입니다.
- [홈 화면 기기 검사](dashboard-device-tests.log): **1개 통과**. 실제 분석 응답의 오적재 두 곳을 로컬 Firestore에 등록하고, 홈을 연 상태에서 새 알림 수신·수치 변경·중복 제외·창고 선택·대응 목록 이동·적재자 회신·QA 완료를 검증했습니다. 전후 전체 재고 문서도 동일함을 확인했습니다.
- [기존 화면 회귀 검사](regression-device-tests-retry.log): **5개 통과, 1개 실패**. 실사 알림·적재자 대응, 12장 목록 구성, 기존 라벨 실사와 수동 확인 흐름은 통과했습니다. 12장 결과 화면 검사는 중간에 `UiAutomation.takeScreenshot()`이 `null`을 반환해 중단됐습니다(`F05ReferencePairsScreenTest.kt:98`). 최초 실행은 로컬 Firebase 종료로 연결에 실패했으며, Java 21로 서버·자료를 복구하고 이전 서버의 로컬 캐시를 초기화한 뒤 재실행했습니다. 집계 수정 검사는 별도의 로그에서 정상 통과했습니다.
- [패키지 검증](verification.json): 테스트 사진 12장 유지, 테스트 계정·테스트 서버 주소·기기 검사 자료의 메인 APK 미포함, APK 해시.
