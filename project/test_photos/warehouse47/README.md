# 실사 창고 선택과 테스트 사진 연결 수정

2026-11-25. 최신 앱: `app/build/outputs/apk/debug/app-debug.apk`.

## 변경한 동작

기존에는 카메라에서 테스트 사진을 선택할 때 사진 목록의 창고 코드가 사용자가 선택한 창고를 덮어썼습니다. 실사 시작 화면의 ‘분석에서 결정’ 항목도 선택 없이 진행하는 것을 허용했습니다.

이제 회사의 재고가 확인된 창고를 먼저 선택해야 카메라·앨범을 열 수 있습니다. 카메라는 회사별 재고를 다시 확인하고 선택한 창고를 상단에 표시합니다. 사진 확인 화면과 분석 요청에서도 같은 창고를 유지하며, 창고가 없거나 테스트 사진의 연결 창고가 다르면 분석을 차단합니다. 서버가 다른 창고의 결과를 반환해도 완료 처리와 오적재 알림 등록을 진행하지 않습니다.

일반 회사 창고는 유지합니다. `isTestData`가 참인 재고만 있는 이전 테스트 창고 중 현재 사진 목록에서 사용하지 않는 창고는 실사 선택 목록에서 제외합니다. 현재 테스트 자료에서는 ‘AI 상품·위치 비교 테스트 창고’와 ‘AI 이미지 테스트 창고 04’가 제외됩니다. 전산 재고 문서는 삭제하지 않았습니다.

| 실사 창고 | 선택할 수 있는 테스트 사진 |
| --- | --- |
| AI 이미지 테스트 창고 01 | 테스트 01·02: 생활용품 A 정상·오적재 |
| AI 이미지 테스트 창고 02 | 테스트 03·04: 생활용품 B 정상·오적재 |
| AI 이미지 테스트 창고 03 | 테스트 05·06: 생활용품 C 정상·오적재 |
| AI 실사 추가 테스트 창고 | 테스트 07~12: 가전·장난감·포장 팔레트 정상·오적재 |

등록된 12장은 유지하고 선택한 창고에 연결된 사진만 표시합니다. 테스트 사진이 연결되지 않은 일반 창고에서는 카메라·앨범을 사용합니다. 카메라의 테스트 사진 버튼은 별도 행으로 옮겨 좁은 화면에서도 보이도록 했습니다.

## 검증

- [앱 빌드·단위 검사](android-build.log): 앱·테스트 APK 빌드 성공, **38개 통과**. 일반 재고 보존, 이전 테스트 창고 제외, 타 회사 창고 미노출, 창고별 사진 필터, 선택 누락·사진 불일치 차단을 포함합니다.
- [기기 검사](device-tests.log): **1개 통과**. 로컬 Firebase 회사 재고로 실제 창고 목록·선택 필수·화면 재생성·카메라의 사진 필터·사진 확인 화면까지 검증했습니다. 분석 요청은 HTTP를 보내지 않는 기록용 API로 선택값 유지와 서버 응답 불일치 차단을 확인했습니다. 전후 전체 재고 문서가 동일합니다.
- [API 검사](backend-tests.log): **8개 통과**. 실제 사진 픽셀 비교와 선택한 창고의 결과를 확인했고, 캐시가 있어도 다른 창고를 요청하면 422로 거부하는 것을 검증했습니다. FastAPI 테스트 클라이언트를 사용하며 운영 서버에는 요청하지 않았습니다.
- [패키지 검사](verification.json): 12장·창고별 사진 수 유지, 테스트 계정과 로컬 검사 자료의 메인 APK 미포함, APK 해시.
