# InvenAI 시연 영상 시나리오

약 6분 동안 정상 실사와 오적재 실사를 비교한 뒤, 오적재 알림을 받은 적재자가 조치를 회신하고 검수자가 승인하는 과정을 보여줍니다. 마지막에 현장 로그로 처리 과정을 확인합니다. 분석 대기 시간은 촬영 환경에 따라 별도로 잡습니다.

## 촬영 준비

- 두 화면을 나란히 배치합니다. 왼쪽은 QA, 오른쪽은 같은 회사의 LOADER 계정으로 로그인합니다. `admin`은 가입 승인용이므로 QA 실사 화면에는 회사·QA 권한이 등록된 계정을 사용합니다.
- 양쪽 모두 최신 APK를 설치하고 인터넷, 분석 서버 연결, 적재자 기기 알림 허용 상태를 확인합니다. 기기 알림 전송에는 PC 서버의 FCM 설정도 준비되어 있어야 합니다.
- 시연 창고는 `AI 이미지 테스트 창고 03`으로 통일합니다. 정상 사진은 `테스트 05 · 생활용품 C 전경 · 정상`, 비교 사진은 `테스트 06 · 생활용품 C 전경 · 오적재`를 사용합니다. 이 오적재 사진의 비교 대상은 두 곳입니다.
- 선택 창고에 이전 시연의 미처리 알림이 있으면 이번 두 건과 구분합니다. 마지막에 미처리 0건을 보여주려면 기존 건까지 확인·처리된 상태에서 촬영합니다.
- 로그인 비밀번호 입력과 서버 인증키는 영상에 담지 않습니다. 분석 서버와 모델을 한 번 실행해 두고, 시작 전에 두 사진의 결과를 확인합니다.
- 발표용 화면에서는 앱·결과·알림을 크게 보여주고 터미널은 준비 단계에서만 사용합니다.

분석 대기를 편집한다면 화면에 `분석 중` 자막을 남겨 처리 중인 장면임을 알립니다. 영상에서 측정하지 않은 처리 속도를 수치로 소개하지 않습니다. 알림 두 건을 모두 승인해야 이번 실사에서 생긴 미처리 건이 모두 정리됩니다.

## 재조치까지 보여주는 추가 장면

본편의 QA 검수 단계에서 첫 번째 건에 `재조치 요청`을 한 번 사용하면 40~60초 정도의 확장 장면을 만들 수 있습니다.

1. QA가 적재자 메모를 확인한 뒤 `재조치 요청`에 “목표 위치 재확인 필요”를 남깁니다.
2. 적재자가 다시 열린 알림을 확인하고 “목표 위치 재확인 완료”로 재검수를 요청합니다.
3. QA가 최종 승인합니다.
4. 이상 이력에서 `발견 → 재적재 회신 → 재조치 요청 → 재적재 회신 → 승인`을 확인합니다.

발표 멘트: “조치가 충분하지 않으면 검수자가 재조치를 요청할 수 있고, 반복된 처리 과정도 각각 기록됩니다.”

## 실제 전산 재고 이동을 보여주는 추가 장면

테스트 사진의 오적재 처리와 전산 재고 이동은 구분해 촬영합니다. 사진 시연에서는 수량이나 전산 위치를 자동으로 바꾸지 않습니다.

승인된 시연용 전산 재고 한 건으로 다음 중 하나를 40~60초 정도 추가합니다.

- `재고 이동`: 이동 가능한 정상 재고를 선택해 다른 위치로 이동하고 재고 상세·작업 이력에서 변경 위치를 확인합니다.
- `전산 재고 재검수`: QA가 시연용 재고의 오적재 조치를 요청하고, 적재자가 조치 위치·수량을 회신한 뒤 QA가 승인합니다. 검수 대기에서는 기존 전산 값이 유지되고, 승인 후 회신한 위치·수량이 반영되는 것을 보여줍니다.

발표 멘트: “사진에서 발견한 이상과 전산 재고의 확정 변경은 구분합니다. 전산 재고는 이동 작업 또는 검수 승인 과정을 통해 반영되고, 변경 전후 값이 이력에 남습니다.”

## 관리자 가입 승인 장면

가입 관리를 소개하고 싶다면 본편 앞이나 뒤에 30~45초를 추가합니다.

1. 별도의 시연 계정으로 회사 코드와 요청 역할을 선택해 회원가입합니다.
2. 해당 계정으로 로그인해 `관리자 승인 대기 중` 화면을 보여줍니다.
3. 관리자가 회사 코드 없이 로그인해 가입 요청을 선택하고 회사·QA 또는 LOADER 역할을 지정해 승인합니다.
4. 승인된 계정이 지정된 회사 코드로 로그인해 역할별 홈으로 이동하는 것을 보여줍니다.

발표 멘트: “회원가입만으로 회사 재고에 접근할 수는 없습니다. 관리자가 소속과 작업 역할을 승인한 계정만 해당 회사의 업무 화면을 사용할 수 있습니다.”

## 촬영 직전 확인

정상·오적재 사진은 동일한 시연 창고로 선택하고, 촬영 전에 두 사진의 결과가 준비된 테스트 전산과 연결되는지 확인합니다. 현재 테스트 사진의 정상 결과를 처음 보는 모든 현장 사진의 정확도로 설명하지 않습니다. 이 영상은 검증된 비교 사진을 통해 정상·오적재 표시와 업무 흐름을 보여줍니다.

적재자 알림이 보이지 않으면 기기 알림·상단 팝업 설정, 앱의 알림 연결 상태, PC 서버 연결을 확인합니다. 백그라운드 알림 장면은 홈 버튼으로 다른 화면에 둔 상태로 촬영합니다. 앱을 기기 설정에서 강제 종료한 상태로 준비하지 않습니다.
