# F03·F04 실제 창고 검증용 촬영 기록

첫 검증에는 전산 재고가 등록된 랙 구역 1곳과 연속된 6~10칸을 사용한다. 전체 사진은 랙 기둥, 선반, 위치 라벨과 적재물이 함께 보이게 찍는다. 이어서 각 칸을 가까이에서 찍으며 랙 위치 라벨, 박스나 파렛트의 실제 상품 코드 또는 바코드, 적재물 경계를 한 프레임에 담는다. 빈 칸은 위치 라벨과 빈 적재면이 함께 보이게 찍는다. 구역이 여러 사진에 나뉘어도 같은 물리적 랙은 같은 그룹으로 기록한다.

## 제출 항목

- 랙 전체 사진 1장과 칸별 근접 사진 원본
- 사진에 찍힌 상품 코드와 위치에서 작업자가 직접 확인한 실물 정보
- 촬영 시점에 전산에서 확인한 해당 위치의 등록 상품 코드와 수량. 동일한 상품이 다른 위치에 등록되어 있다면 해당 등록 정보도 함께 제공한다.
- 정상, 오적재, 빈 칸 사례를 표시한 아래 표. 현장에 없는 사례는 추가 촬영 때 보완한다.

| 랙 그룹 | 전체 사진 | 근접 사진 | 랙 위치 코드 | 실물 상품 코드 | 전산 위치의 상품 코드 | 전산 수량 | 현장 판정 |
|---|---|---|---|---|---|---:|---|
| | | | | | | | |

촬영 시각과 창고 식별자를 함께 적는다. 한 칸에 상품이 여러 종류면 각각 기록한다. 빈 칸은 실물 상품 코드에 `빈 칸`을 적고, 전산에도 상품이 없으면 전산 상품 코드에 `없음`을 적는다. 상품 코드가 바코드로만 표시되어 있으면 코드 종류와 바코드 값도 기록한다.

## 평가 방법

1. 전체 및 근접 사진에서 사람이 직접 적재물과 두 라벨 위치를 표시하고, 전산 스냅샷과 함께 정답을 고정한다.
2. 동일 랙의 전체 사진, 근접 사진, 재촬영 및 잘라낸 이미지를 한 그룹에 묶는다. 파일 복제와 촬영 그룹 중복은 학습 전에 검사한다. 최종 검증에는 튜닝에 쓰지 않은 랙을 사용한다.
3. 같은 칸의 전체 사진과 근접 사진을 각각 현재 F03·F04로 실행한다. 적재물 탐지, 위치 코드 판독, 상품 코드 판독, 두 코드의 적재물 연결, 전산 대조를 순서대로 기록한다.
4. 정상 적재와 오적재는 각 정답 건수 전체를 분모로 보고한다. 탐지 누락과 확인 보류도 분모에 포함한다. 오적재를 정상으로 처리한 건수, 정상 적재를 오적재로 처리한 건수, 빈 칸을 적재물로 판정한 건수를 각각 집계한다.

6~10칸의 첫 촬영은 실패 원인과 촬영 방법을 확인하는 데 쓴다. 90% 목표는 여러 랙에서 수집한 독립 검증 데이터로 판정한다.
